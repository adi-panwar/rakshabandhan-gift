# Raksha Bandhan Gift Website ❤️

## Files
- index.html
- style.css
- script.js
- assets/bhai.jpg
- assets/puzzle.jpg
- assets/qr.png

## Put your photo
Replace:
assets/bhai.jpg

with your own photo. Keep the same filename.

## Puzzle
Replace:
assets/puzzle.jpg

with any square-ish festive/photo image you want. The puzzle automatically cuts it into a 3x3 image puzzle.

## QR
The included `assets/qr.png` is the QR-style image you provided as a reference. If it is not your intended QR, replace it with your own QR image using the same filename.

## Run
Open the folder in VS Code and double-click `index.html`, or use the Live Server extension.

## Personalize
Search in `index.html` for the message text and change it to your own words.

The website uses no backend and works locally.
